# Mission: Forward Deployed Engineering

## Why
Narendra wants to be hired as a Forward Deployed Engineer at a frontier AI lab
(Anthropic Applied AI, OpenAI FDE, or a well-funded agent startup). He has the build
half already — see the agent-engineering workspace at `../learnaiagents` — and is
deliberately closing the half that workspace excludes: going into a customer's
environment, finding the problem nobody has written down, cutting it to something that
ships, and owning whether it survives contact with production.

## Success looks like
- Can take a vague executive ask and produce, in under an hour, a scoped first deployment with a named user, a measured baseline, a thin slice, and a kill criterion — and defend every line
- Can run a discovery conversation that surfaces the real workflow instead of the requested feature
- Can design the pilot→production path for an enterprise: VPC/on-prem, SSO, data residency, security review, and the IT blockers that actually kill deployments
- Can turn "the agent works" into an acceptance test the customer signs — the eval work from `../learnaiagents` L08/L09 used as a commercial instrument, not a dev tool
- Can hold a hostile customer conversation: slipped date, refused feature, non-determinism explained to a non-technical VP
- Can tell which custom work should become product and which should stay a one-off — the line between FDE and consulting
- Has one portfolio deployment artifact plus a 30-minute defense that survives an FDE panel

## Constraints
- 20–30 minute sessions, most days. One tangible win per lesson.
- Already a competent SWE with real agent-engineering depth. Never re-teach engineering fundamentals, agent loops, evals mechanics, or RAG — reference `../learnaiagents` instead.
- Customer-facing experience is thin: demos and support escalations, always inside someone else's process. Has never owned a scoping decision or a deployment. This is the floor.
- Written deliverables must be produced literally, not summarised. A verdict is not a deliverable. (Carried over from `../learnaiagents/NOTES.md`.)

## Out of scope
- Sales: pricing, contracts, quota, pipeline. FDEs work post-signature; scoping is in, selling is out.
- Management: building and running an FDE org, comp ladders, pod staffing. He is interviewing as an IC.
- Palantir ontology/Foundry product specifics. The model is the lesson, not the toolchain.
- Resume and recruiter tactics. The bet is that a defensible artifact beats positioning.
